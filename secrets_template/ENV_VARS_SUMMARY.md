## 📋 SUPABASE SETUP (Keep for Auth + Storage + Realtime)

### 1. Create Supabase Project
- Project name: `mathgenius`
- Region: Close to Nigeria (e.g., South Africa)

### 2. Enable Google OAuth
- Authentication → Providers → Google → Enable
- Add redirect URLs:
  - `https://mathgenius.guru/**`
  - `http://localhost:5173/**` (for local dev)

### 3. Run Database Schema
Copy/paste `database/init.sql` into Supabase SQL Editor and run.

| Credential | Location |
